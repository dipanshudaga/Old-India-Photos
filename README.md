# Old India Photos

A modern, interactive gallery showcasing historical photographs from India, preserving and presenting the rich visual heritage originally published on [oldindianphotos.in](https://www.oldindianphotos.in/).

**Live Site:** https://dipanshudaga.github.io/Old-India-Photos/

## Features

- **Smart Search & Filtering** – Search by keywords or filter using popular tags with OR logic
- **Responsive Masonry Layout** – Adaptive column grid that works beautifully on all screen sizes
- **Infinite Scroll** – Seamlessly browse thousands of historical images
- **Image Modal** – View high-resolution images with descriptions
- **URL State Management** – Share filtered views and bookmarked images

## Tech Stack

- Vanilla JavaScript (no frameworks)
- Flexi-masonry column-based layout
- Python scripts for data processing and scraping
- GitHub Pages for hosting

## Local Development

```bash
# Serve the site locally
cd site
python3 -m http.server 8080
# Visit http://localhost:8080
```
